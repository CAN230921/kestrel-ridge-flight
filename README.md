Kestrel Ridge is a zero-dependency WebGL2 3D flight simulator featuring a 6-DOF aerodynamic flight model, structural subsystem damage, a 320x320 procedural archipelago with 3D pine forests and landmarks, dual chase and illuminated glass-cockpit views, and four distinct flight sorties.

## Run it

```sh
node serve.ts
```
